# South Indian Wedding Invitation Preview

This is a static wedding invitation microsite. It does not need `npm install`.

## Preview locally

```bash
npm run build
npm start
```

The preview server binds to all interfaces on port `4173` so hosted development environments can expose it through their **Ports**, **Preview**, or **Open Browser** panel.

Open the forwarded preview for port `4173`. If you are running directly on your own machine, open:

```text
http://localhost:4173/index.html
```

> In a remote container, `127.0.0.1` in your personal browser may point to your own computer, not the container. Use the environment's forwarded URL for port `4173`.
